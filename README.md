# User Management API

## Overview

This is a simple User Management API built with ASP.NET Core Minimal APIs. It allows you to perform CRUD operations (Create, Read, Update, Delete) on user data.

## Features

- Retrieve a list of all users
- Retrieve a specific user by ID
- Add a new user
- Update an existing user's details
- Remove a user by ID

## Prerequisites

- [.NET SDK](https://dotnet.microsoft.com/download) installed on your machine.
